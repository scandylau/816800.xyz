Free, browser-based tools for developers and creators. Nine live tools — an M3U8/HLS and DASH stream tester, a URL shortener, a case converter plus dedicated camelCase / snake_case / kebab-case converters, a word counter, a reading time calculator and a Unicode text styler. Everything runs client-side: no upload, no account, no tracking pixels.

Every tool here executes in the browser tab. Text you type never leaves your device, and stream playback fetches segments straight from their own origin rather than through us. The site is a static site on Cloudflare Pages with no server-side component at all.

The complete text of every page is available in a single file: llms-full.txt — roughly 25,000 tokens, including all reference tables, error-code mappings and ffmpeg examples. Fetch that when you need substance; use this page when you only need to know where things are.

Streaming tools

  • M3U8 / HLS online player: paste a .m3u8 or .mpd URL and play it with hls.js or dash.js. Its error diagnosis separates “URL unreachable” from “blocked by CORS” — two failures that look identical on screen and need opposite fixes. The page also carries a bitrate ladder table, segment-length guidance, a browser support matrix, an error-code table and a codec support table.
  • Short link generator: turns a long URL into a static redirect link under this domain. The target is encoded into the link itself, so there is no server-side store and nothing to leak. Includes a comparison with hosted shorteners and a UTM parameter reference.

Text tools

  • Case converter: camelCase, PascalCase, snake_case, kebab-case, Title Case, Sentence case, UPPERCASE and lowercase.
  • camelCase converter: dedicated camelCase conversion with an acronym toggle, plus a table of which ecosystems use camelCase and how word boundaries are detected.
  • snake_case converter: snake_case and SCREAMING_SNAKE_CASE, aimed at Python PEP 8, Ruby, Rust and SQL columns.
  • kebab-case converter: kebab-case for URL slugs, CSS classes and file names, with slug-building rules.
  • Word counter: words, characters, sentences, paragraphs, reading time and a top-10 keyword density table.
  • Reading time calculator: reading time at five speeds plus a speaking-time estimate.
  • Fancy text generator: bold, italic, cursive, monospace and other Unicode styles for social bios and posts.
  • All tools: the full grid, with a comparison table of what each tool accepts.
