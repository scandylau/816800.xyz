Short Link / Redirect

Paste a long URL to get a branded share link · No backend · No upload

这是什么、它不是什么

这是一个零后端的链接中转工具：它不会把你的链接存进任何数据库，而是把长链接编码进地址栏的 #u= 片段里，生成一个形如 816800.xyz/short-link/go.html#u=… 的分享链接。任何人点开都会在你的浏览器里解码并跳转。

为什么链接「并不短」？

真正的「字节级超短码」（如 bit.ly/abc）需要在服务器上保存「短码 ↔ 长链接」的映射表。本站是纯静态站点，没有数据库，因此无法提供这种短码。本工具的价值在于品牌化、零上传、永久可用——链接随站点常驻，且长链接不会经过任何第三方服务器。

安全说明

  • 跳转页只接受 http:// 与 https:// 协议，自动拦截 javascript:、data: 等危险协议，避免被用作开放重定向。
  • 编码后的内容仅存在于你分享的链接本身，不会被本站服务器接收或存储。
  • 若你想要可对外分发的真·超短码，需要为站点加上 Cloudflare Pages Functions + KV（方案 B），届时可另行部署。

What this is — and what it is not

This is a backend-free link redirector: it stores nothing in any database. Instead it encodes the long URL into the #u= fragment of the address bar, producing a share link like 816800.xyz/short-link/go.html#u=…. Anyone who opens it decodes and redirects entirely in their own browser.

Why the link is "not actually short"

A true "byte-level short code" (e.g. bit.ly/abc) requires a server-side table mapping short codes to long URLs. This site is fully static with no database, so it cannot offer such codes. The value here is branding, zero upload, and permanent availability — the link lives with the site, and the long URL never touches any third-party server.

Safety notes

  • The redirect page only accepts http:// and https:// schemes, blocking dangerous ones like javascript: or data: to prevent open-redirect abuse.
  • The encoded content lives only inside the link you share — it is never received or stored by our server.
  • If you want a real, shareable short code, the site would need Cloudflare Pages Functions + KV (Approach B), which can be deployed separately.
