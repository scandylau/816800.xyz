Short Link / Redirect

Paste a long URL to get a branded share link · No backend · No upload

这是什么、它不是什么

这是一个零后端的链接中转工具：它不会把你的链接存进任何数据库，而是把长链接编码进地址栏的 #u= 片段里，生成一个形如 816800.xyz/short-link/go.html#u=… 的分享链接。任何人点开都会在你的浏览器里解码并跳转。

为什么链接「并不短」？

真正的「字节级超短码」（如 bit.ly/abc）需要在服务器上保存「短码 ↔ 长链接」的映射表。本站是纯静态站点，没有数据库，因此无法提供这种短码。本工具的价值在于品牌化、零上传、永久可用——链接随站点常驻，且长链接不会经过任何第三方服务器。

安全说明

  • 跳转页只接受 http:// 与 https:// 协议，自动拦截 javascript:、data: 等危险协议，避免被用作开放重定向。
  • 编码后的内容仅存在于你分享的链接本身，不会被本站服务器接收或存储。
  • 若你想要可对外分发的真·超短码，需要为站点加上 Cloudflare Pages Functions + KV（方案 B），届时可另行部署。

What this is — and what it is not

This is a backend-free link redirector: it stores nothing in any database. Instead it encodes the long URL into the #u= fragment of the address bar, producing a share link like 816800.xyz/short-link/go.html#u=…. Anyone who opens it decodes and redirects entirely in their own browser.

Why the link is "not actually short"

A true "byte-level short code" (e.g. bit.ly/abc) requires a server-side table mapping short codes to long URLs. This site is fully static with no database, so it cannot offer such codes. The value here is branding, zero upload, and permanent availability — the link lives with the site, and the long URL never touches any third-party server.

Safety notes

  • The redirect page only accepts http:// and https:// schemes, blocking dangerous ones like javascript: or data: to prevent open-redirect abuse.
  • The encoded content lives only inside the link you share — it is never received or stored by our server.
  • If you want a real, shareable short code, the site would need Cloudflare Pages Functions + KV (Approach B), which can be deployed separately.

How to use it

  1. Paste the destination URL into the field above, including https://.
  2. Press Generate. The tool URL-encodes the address and appends it after #u=.
  3. Copy the result and share it anywhere — chat, email, a printed QR code, a slide deck.
  4. When someone opens it, go.html decodes the fragment in their own browser and redirects. No server lookup, no mapping table, no delay.

Because the destination travels inside the link, the result is longer than a classic short code. That is the trade-off for a tool that never sees your URL.

When a branded redirect beats a short code

  • Internal docs and wikis — a long Confluence, Notion or SharePoint URL nobody should have to retype.
  • Print and QR codes — one stable link on your own domain that keeps working as long as this site does.
  • Email and newsletters — wrap a URL already carrying six tracking parameters into a single branded link.
  • Sensitive destinations — staging environments, signed download links, or anything you would rather not store in a third party's database.
  • Restricted networks — the link resolves without contacting a shortening service, so it works wherever this domain is reachable.

Add UTM tags before you shorten

If the link is for a campaign, attach your tracking parameters first, then run the finished URL through this tool. UTM tags tell your analytics where a visitor actually came from:

The five standard UTM parameters
ParameterWhat it answersExample value
utm_sourceWhich site or sender sent the clicknewsletter, reddit
utm_mediumWhich channel type it wasemail, social, cpc
utm_campaignWhich campaign it belongs tospring_sale
utm_termWhich keyword or varianthls+player
utm_contentWhich link inside the same messagefooter_button

Put together, a tagged URL looks like this:

https://example.com/landing?utm_source=newsletter&utm_medium=email&utm_campaign=spring_sale

Keep every value lowercase and use underscores instead of spaces. Mixed case and stray spaces are the most common reason one campaign shows up in reports under three different names.

Frequently asked questions

Does the link expire?

No. Nothing is stored, so there is nothing to expire. The link keeps working as long as the destination does and this page exists.

Can I see how many people clicked?

Not here. Counting clicks needs a server, which is exactly what this tool avoids. If you need numbers, add UTM parameters and read them in your own analytics.

Is my destination URL private?

It is encoded, not encrypted. Anyone holding the link can decode it in a browser. Treat it as readable, never as secret — do not put tokens, passwords or private keys in a URL you share.

Is there a length limit?

Most browsers and servers handle URLs up to roughly 2,000 characters, but some chat apps and email clients truncate much earlier. Because the encoded form is longer than the original, very long URLs can hit that ceiling and break when pasted.

Can I use it for affiliate or paid links?

Yes, as long as the destination is yours to promote and the programme allows cloaking. Some affiliate networks require the referral to be visible; check their terms before wrapping the link.

Why not just use a real shortener?

If you need byte-short codes and click statistics, use one — they are good at that. Reach for this tool when you would rather not hand your destination URL to somebody else's database.
