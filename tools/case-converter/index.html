How to Change Text Case (and When It Matters)

Case is not just decoration. The convention you pick changes how readable a headline feels, how professional an email looks, and whether your code passes a linter. This converter handles the common conventions in one click, entirely in your browser.

The everyday writing styles

Sentence case capitalizes only the first letter of each sentence. It is the default for body copy, UI microcopy and most button labels, because it reads like natural language.

lowercase removes every capital letter. Designers use it for a calm, modern look in logos and navigation, and it is handy for normalizing messy data before comparison.

UPPERCASE is loud. Use it sparingly for short labels, warnings or legal clauses. Long passages in all caps are measurably harder to read, so avoid it for paragraphs.

Title Case capitalizes the main words of a headline. Most style guides keep short words such as a, an, the, of, in and to in lowercase unless they start or end the title.

The developer naming styles

camelCase joins words with no separator and capitalizes every word after the first. It is the JavaScript convention for variables and functions.

PascalCase is camelCase with a leading capital, used for class names, React components and types.

snake_case separates words with underscores and is common in Python, Ruby and database column names.

kebab-case uses hyphens and is the standard for CSS classes, HTML attributes and URL slugs. Search engines treat hyphens as word separators, which makes kebab-case the safest choice for readable URLs.

CONSTANT_CASE combines uppercase with underscores for constants and environment variables.

Practical uses

  • Clean up a list of names or product titles before importing into a spreadsheet.
  • Convert a design headline into a URL slug you can paste straight into a CMS.
  • Rename a batch of variables to match your project linting rules.
  • Normalize user-submitted tags so duplicates collapse into one value.
Tip: converting to lowercase first and then into the target style usually gives the cleanest result, because it removes stray capitals hidden inside words.

Frequently asked questions

What does a case converter do?

A case converter rewrites your text into a different letter-case convention, from simple upper and lower case through to programming styles such as camelCase, snake_case and kebab-case.

What is the difference between Title Case and Sentence case?

Title Case capitalizes the first letter of every significant word and suits headlines. Sentence case capitalizes only the first letter of each sentence and reads more naturally in body copy.

When should I use camelCase, snake_case or kebab-case?

camelCase is standard for JavaScript variables, snake_case is common in Python and Ruby, and kebab-case is typical for CSS classes, HTML attributes and URL slugs.

如何转换英文大小写（以及什么时候该用哪一种）

大小写不只是排版细节。选哪种规范，会影响标题的观感、邮件的专业度，以及代码能否通过 lint 检查。本工具一键覆盖常见规范，全程在浏览器内完成。

日常书写类

句首大写（Sentence case）：只大写每个句子的首字母，适合正文、界面文案和按钮标签，读起来最自然。

全小写（lowercase）：去掉所有大写。设计师常用它营造克制的现代感，也适合在比对数据前先做归一化。

全大写（UPPERCASE）：视觉冲击强，建议只用于短标签、警告或法律条款。整段全大会明显降低阅读速度。

标题式（Title Case）：大写标题中主要单词的首字母。多数风格指南会让 a、an、the、of、in、to 这类短词保持小写，除非它们位于标题首尾。

编程命名类

camelCase：首词小写、后续词首字母大写，是 JavaScript 变量与函数的主流写法。

PascalCase：每个词首字母都大写，用于类名、React 组件和类型名。

snake_case：用下划线连接，常见于 Python、Ruby 与数据库字段名。

kebab-case：用连字符连接，是 CSS 类名、HTML 属性和 URL slug 的标准写法。搜索引擎把连字符视作分词符号，因此它对可读链接最友好。

CONSTANT_CASE：全大写加下划线，用于常量和环境变量。

典型用途

  • 导入表格前，统一整理一批姓名或产品标题。
  • 把设计稿标题转成可直接粘贴进 CMS 的 URL slug。
  • 批量重命名变量，使其符合项目 lint 规则。
  • 归一化用户提交的标签，让重复值合并为一个。
小技巧：先转成全小写再转成目标风格，通常结果最干净，因为这样可以清掉单词内部残留的大写字母。
