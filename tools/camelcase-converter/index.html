What camelCase Is and When You Should Use It

camelCase joins words without separators and capitalizes every word after the first: userName, parseHttpResponse, totalItemCount. It is the default naming style for JavaScript and the convention most JSON APIs use for their keys. This page converts any text into camelCase in one click, entirely inside your browser.

camelCase vs PascalCase vs the rest

The difference between camelCase and PascalCase is only the first letter. camelCase starts lowercase and is used for variables, functions and object keys. PascalCase starts uppercase and is reserved for things that define a type or a component: classes, React components, TypeScript interfaces and C# methods.

How the conversion actually works

A converter has to decide where one word ends and the next begins. This one splits on three signals: spaces and punctuation, an existing underscore or hyphen, and a lowercase-to-uppercase transition inside a word. Every word is then lowercased except the first letter of each word after the first.

user name             → userName
User Name             → userName
user_name             → userName
user-name             → userName
USER NAME             → userName
getUserById()         → getUserById
2 fast 2 furious      → 2Fast2Furious

Note the last line. Many converters drop digits or push them somewhere odd, because a number is not a word. Keeping digits attached to the word they sit in is what makes the result usable as a real identifier — though since most languages forbid a name that starts with a digit, you will want to rename that one.

Acronyms: the part most converters get wrong

Given parse HTTP response, should the result be parseHTTPResponse or parseHttpResponse? Both appear in production code, and the major style guides disagree. Google's Java Style Guide treats an acronym as an ordinary word, which yields parseHttpResponse. Apple's Swift guidance and a large amount of JavaScript keep the run of capitals intact, giving parseHTTPResponse.

The checkbox above lets you choose. Leave it on to keep consecutive capitals together; turn it off to spread them into separate words. If your project runs a linter, match whatever the linter enforces.

Converting camelCase back out

camelCase is rarely the final form. You convert out of it whenever a value crosses an ecosystem boundary:

  • To kebab-case when the value becomes a URL slug or a CSS class.
  • To snake_case when a JSON key lands in Python, Ruby or a SQL column.
  • To SCREAMING_SNAKE_CASE when it becomes an environment variable.
getUserById   → get-user-by-id    (URL slug)
getUserById   → get_user_by_id    (Python attribute)
getUserById   → GET_USER_BY_ID    (environment variable)

Both are one click away on the snake_case converter and the kebab-case converter.

Frequently asked questions

What is camelCase?

camelCase writes multi-word identifiers without spaces and capitalizes every word except the first, as in totalItemCount. The capitals in the middle are said to look like a camel's humps.

Is camelCase the same as lowerCamelCase?

Yes. lowerCamelCase is the formal term for camelCase with a lowercase first letter, used to distinguish it from UpperCamelCase (PascalCase). In practice people say camelCase and mean lowerCamelCase.

Does this converter upload my text?

No. It is pure client-side JavaScript. Your text stays inside your browser tab and never reaches a server.

Can I convert a whole list of identifiers at once?

Yes. Paste one per line. Newlines are treated as word boundaries, so each line becomes its own converted value.

Why did my output lose the numbers?

It should not. Digits stay attached to the word they sit in. If a result looks wrong, the input probably contained a separator that was read as a boundary; converting to lowercase first usually fixes it.

Should acronyms stay uppercase?

Match your style guide. Google's Java guide gives parseHttpResponse; Apple's Swift guidance and much JavaScript use parseHTTPResponse. The checkbox above switches between the two.
