What kebab-case Is and Why URLs Depend on It

kebab-case writes multi-word identifiers in lowercase with hyphens between words: get-user-by-id, hero-section-title, how-to-test-hls-streams. It is the standard for CSS classes, HTML attributes and URL slugs. This generator converts any text into kebab-case in one click, inside your browser.

Why slugs use hyphens, not underscores

Google has said plainly that it treats a hyphen as a word separator and an underscore as a word joiner. A URL ending in best-practice-2026 can match queries for best, practice and 2026; the same slug written best_practice_2026 is read as one token. Hyphens are also easier to pick out in underlined link text, where an underscore hides beneath the underline.

Where kebab-case is the standard

  • URL slugs — the single most important use. Lowercase, hyphenated, no stop words.
  • CSS class names — including BEM, where .card__title--large is built from kebab-cased words.
  • HTML attributes — data-user-id, aria-label.
  • npm package names — the registry enforces lowercase and allows hyphens.
  • File and folder names — safe across case-insensitive filesystems on macOS and Windows.
  • Web components — custom element names must contain a hyphen.

How the conversion works

The converter splits on spaces, punctuation, underscores and camelCase transitions, lowercases every word, then joins with a single hyphen. Duplicate and trailing hyphens are collapsed, so messy input still produces a clean slug.

Frequently asked questions

What is kebab-case?

kebab-case writes multi-word identifiers in lowercase with hyphens between words, as in get-user-by-id. It is the standard for CSS classes, HTML attributes and URL slugs.

Why not underscores in URLs?

Google treats a hyphen as a word separator and an underscore as a word joiner. Hyphens also stay visible in underlined link text.

Can I use kebab-case for variable names?

No. A hyphen is read as a minus sign in JavaScript, Python, Java and C#. Use camelCase or snake_case for identifiers and reserve kebab-case for CSS, HTML, URLs and file names.

What is Train-Case?

Train-Case keeps the hyphens but capitalizes each word, as in Get-User-By-Id. It appears in some HTTP headers and display labels; lowercase kebab-case is the common default.

Should stop words be removed from a slug?

Usually. Words like a, the, of and for add length without meaning. Shorter slugs are easier to read and share.

Does this converter upload my text?

No. It is pure client-side JavaScript, so your titles and slugs never leave your browser.
