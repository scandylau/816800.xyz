How to use it

  1. Pick a tool from the grid above — the five live ones carry the ONLINE badge.
  2. Paste, drop or type your input. Results update as you type, computed on your own device.
  3. Copy the result. There is no export button to unlock and nothing to download.

Streaming work starts with the M3U8 player. Paste a .m3u8 or .mpd URL and it tells you whether the stream fails because the link is dead or because a CORS header is missing — two failures that look identical on screen and need opposite fixes.

Frequently asked questions

Are the tools really free?

Yes. No usage caps, no watermarks, no trial period. The site may display advertising to cover hosting, but no feature sits behind a payment or a login.

Does anything I type leave my device?

No. Text conversion, counting and font mapping run in the browser tab. Stream playback fetches the segments you asked for directly from their own server, which is unavoidable — but nothing passes through us.

Do I need to install anything?

No. If your browser can open this page it can run every tool here. An up-to-date Chrome, Edge, Firefox or Safari gives the best results, particularly for HLS and DASH playback.

Which tool should I try first?

If you work with video, the M3U8 player — it is the one tool here you cannot easily get elsewhere. If you work with text, the word counter gives length, reading time and keyword density in a single pass.

How often are new tools added?

Roughly one every one to two months. A tool only ships if it solves a problem we have actually hit, runs entirely client-side, and beats what already ranks for it — which is why the grid grows slowly.

Something is broken. Who fixes it?

Us, usually within a few days of hearing about it. Send the tool name, your input and your browser through the contact page — a reproducible report is the fastest route to a fix.
