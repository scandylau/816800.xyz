Changelog

Last updated: September 19, 2026

This site is maintained by hand, a few hours a week. This page records every change that affects what you see or what the tools do — new tools, rewritten guides, fixes, and measurement work. Newest first. There is no automation behind these entries; each one maps to a real editing session.

September 19, 2026

  • Revision dates everywhere. All thirty content pages now show Last updated at the top and mirror the same value into their structured data. Before this, only the eleven guides carried any date signal at all, so a returning visitor had no way to tell whether a tool page was current.
  • Authoritative sources cited. Six pages now link directly to the documents the software actually conforms to: RFC 8216, Apple's HLS documentation, MDN on CORS, the hls.js and dash.js source trees, the Unicode code chart behind the fancy text styles, DASH-IF guidelines and VideoLAN. Claims no longer rest on our paraphrase of a specification.
  • Editorial policy published. The about page gained a How we test and publish section: six concrete rules covering measured numbers, re-checked test sources, dated pages, no paid placement, no bulk generation and visible corrections.
  • Transport hardening. Added an HSTS header alongside nosniff, a referrer policy, frame options and a permissions policy. Fullscreen playback and clipboard copy are deliberately left enabled, so neither gets broken.

September 17, 2026

  • Real measurements published. We fetched four public test streams (Apple BipBop, two Mux assets, Sintel) with real HTTP requests and published the actual numbers — playlist sizes, segment durations and byte counts, response times, and CORS/cache headers — on the M3U8 player page. One finding from our own network: Apple's BipBop playlist returned no Access-Control-Allow-Origin header at all, which is exactly the failure mode most guides only describe in theory.
  • Real screenshots added. The player page and the playback troubleshooting guide now include captures of the actual interface: idle state, a live playback session, and a genuine CORS failure with the diagnostic panel output.
  • Homepage cleaned up. Removed eight placeholder cards for unbuilt tools. The tool grid now shows only the five tools that actually work.
  • Disclaimer page added (/disclaimer/) covering tool-output boundaries, streaming and copyright, advertising, and liability limits.
  • Cookie consent implemented. Analytics now load only after you accept; refusing means no statistics script, no cookies, no requests. The privacy policy was updated to describe this precisely.
  • Author bylines added to every guide, with a consistent editor identity and areas of expertise.

September 15, 2026

  • AI discovery files deployed. Added llms.txt (v2 format), a full-text llms-full.txt mirror of all site content, and the AI Discovery Files set (ai.txt, ai.json, identity.json, brand.txt, faq-ai.txt). Content is licensed to AI engines for retrieval and citation with attribution, but not for training.

September 10, 2026

  • Content depth overhaul. Every thin page was rewritten: the privacy policy gained GDPR and CCPA sections, and five HLS/M3U8 guides were expanded past 1,000 words each with reference tables (bitrate ladders, status codes, hls.js error recovery, codec support). Site-wide English word count roughly doubled.

September 5–6, 2026

  • Friends page launched (/links/) listing two partner sites with editorial descriptions.
  • Flagship page strengthened with new sections on how HLS works, bitrate ladders, and cross-links between each tool and its related guides.

September 1–2, 2026

  • Accessibility pass: text contrast raised to meet WCAG AA across the theme.
  • Footer redesigned into a four-column grid; navigation dropdown regrouped with descriptions.
  • Three new guides for the text tools (case converter, word counter, fancy text generator).

August 30–31, 2026

  • Site switched to English-first. All pages now render English by default; Chinese remains available as a switchable version.
  • Three new tools shipped: Case Converter, Word & Keyword Counter, and Fancy Text Generator — all running entirely in the browser.

August 28, 2026

  • Four new streaming guides: DASH vs HLS, player recommendations, short-link guide, and HLS live vs VOD.

August 19–21, 2026

  • Analytics and monetization groundwork: GA4 connected, ads.txt added.
  • SEO foundation: sitemap, robots.txt, Open Graph/Twitter cards, structured data, and the first three HLS guides.
  • Logo and favicon designed and wired into the header.

August 18, 2026

  • Initial launch: M3U8/DASH player with CORS diagnostics and history, static short-link generator, and the first legal pages.

How updates happen

Changes ship when they are ready, not on a schedule. Typical cadence is one to three focused sessions per week. When a tool gains or loses an ability, this page says so on the day it happens. If you spot something that works differently from what is described here, the contact page is the fastest way to reach us.
